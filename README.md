# 📍 位置追踪系统 - 家庭精简版

一个极简的家庭用位置追踪解决方案：30分钟自动上报位置，网页查看记录。

## 🎯 项目目标

- ✅ **家庭专用**：仅供你和家人使用，不涉及第三方
- ✅ **隐私保护**：最小化数据采集，严格的权限控制
- ✅ **省电稳定**：优化后台运行，平衡定位精度和续航
- ✅ **简单可靠**：轻量级架构，易于部署和维护

## 📊 系统概览

### 核心功能
- 📱 **Android客户端**：每30分钟自动采集位置并上报
- 🖥️ **Web界面**：查看位置记录，高德地图跳转
- 🔒 **安全认证**：固定Token + HTTPS传输

### 精简架构

## 🚀 快速开始

### 🚀 三步部署（精简版）

#### 1. 生成Token & 数据库
```bash
# 生成32位Token（保存好）
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# 创建MySQL数据库
CREATE DATABASE location_tracker;
```

#### 2. 启动后端
```bash
cd backend
npm install

# 编辑config.js设置数据库和Token
npm start
```

#### 3. 部署前端 + 安装App
```bash
# 前端部署
cd frontend
npm install && npm run build

# Android构建
# 用Android Studio打开android目录，构建APK
```

## 🔧 配置指南

### 后端配置
1. 复制 `.env.example` 为 `.env`
2. 配置数据库连接信息
3. 设置API_TOKEN
4. 运行数据库初始化脚本

### 前端配置
1. 修改 `src/api/location.js` 中的API_BASE_URL
2. 设置正确的Bearer Token
3. 构建并部署静态文件

### Android配置
1. 修改 `LocationApiService.kt` 中的BASE_URL
2. 设置正确的API Token
3. 构建APK安装包

## 🔒 安全特性

### 数据保护
- **最小化采集**：仅收集必要的地理位置信息
- **传输加密**：强制HTTPS，防止数据泄露
- **存储安全**：本地数据加密，服务器定期清理

### 访问控制
- **Token认证**：每次API请求都需要有效Token
- **IP限制**：可选的IP白名单访问控制
- **请求限流**：防止恶意高频请求

### 隐私保障
- **用户同意**：首次使用强制显示隐私协议
- **随时暂停**：用户可随时停止位置采集
- **数据删除**：支持删除历史位置数据

## 📈 性能优化

### 省电策略
- **智能定位**：平衡精度模式，减少GPS使用
- **批量上报**：减少网络请求频率
- **后台优化**：WorkManager自动管理任务生命周期

### 网络优化
- **断网缓存**：离线时本地存储，恢复后补发
- **请求重试**：指数退避策略，提高成功率
- **数据压缩**：最小化传输数据量
